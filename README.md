# NiftyEdge Pro 🎯

**Real-Time NSE Options Intelligence Platform**  
Live tips · Adaptive accuracy tracking · 9-factor signal engine · Windows desktop app

---

## 📸 What It Does

NiftyEdge Pro streams live NSE option chain data and generates professional buy/sell signals using a weighted statistical model that learns from its own outcomes over time.

| Feature | Details |
|---|---|
| **Data** | Live NSE option chain via Python proxy (no CORS) |
| **Signals** | 9-factor model: PCR · Bull Prob · OI Change · Max Pain · EMA · RSI · Momentum · VWAP · IV |
| **Timeframes** | 10 Min · 20 Min · 30 Min · 1 Hour · 3 Hour |
| **Logging** | Every tip logged to SQLite with entry/target/SL |
| **Accuracy** | Auto-resolves WIN/LOSS · Per-timeframe accuracy tracking |
| **Learning** | Adaptive weights update after each outcome (Bayesian-inspired) |
| **Desktop App** | Native Windows app via `app.py` (tkinter + pywebview) |

## 🧠 Signal Model

Signals are generated by scoring 9 independent factors, each weighted adaptively:

| Factor | Bullish Condition | Max Score |
|---|---|---|
| **PCR (Put-Call Ratio)** | PCR > 1.4 | ±2 |
| **Bull Probability** | Black-Scholes P(up) > 65% | ±2 |
| **OI Change Pattern** | Short covering (both OI falling) | ±2 |
| **Max Pain Distance** | Spot below max pain | ±1.5 |
| **Trend (EMA9/21)** | EMA9 > EMA21 + bullish candle | ±2 |
| **RSI (14)** | RSI < 35 (oversold) | ±1.5 |
| **Momentum (ROC)** | ROC > 0.5% | ±1 |
| **VWAP Position** | Spot above VWAP | ±0.5 |
| **IV Rank** | IV < 12% (cheap options) | ±0.5 |

**Bonus factors:** Bollinger Band breakout (±1), Stochastic K confirmation (±0.5)

- Score ≥ +3 → **BUY**
- Score ≤ −3 → **SELL**  
- Otherwise → **NEUTRAL**

## 📊 Adaptive Learning

Every BUY/SELL signal is logged to a local SQLite database (`niftyedge_tips.db`).

The server monitors option prices every 30 seconds and auto-resolves outcomes:
- Price hits **Target** → marked **WIN**
- Price hits **Stop Loss** → marked **LOSS**
- Timeframe expires → marked **EXPIRED**

On each resolved outcome, factor weights are updated:

```
weight += learning_rate × magnitude × sign
```

Where `sign = +1` for WIN, `−1` for LOSS, `magnitude = |P&L| / 10` (capped at 2.0), `learning_rate = 0.05`.

Weights are saved to the database and reloaded on every server restart. Over many trades, the model converges toward the factors that are most predictive for each specific timeframe.

## ⚙️ Configuration

Edit the top of `server.py` to change these settings:

```python
POLL_INTERVAL = 3      # Seconds between NSE fetches
CANDLE_MINS   = [10, 20, 30, 60, 180]   # Timeframes to build
MAX_CANDLES   = 300    # Candles kept per timeframe in memory
DB_PATH       = 'niftyedge_tips.db'     # SQLite database file
```
